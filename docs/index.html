Moodle files, one click, any folder.

Moodrop puts a save button next to every file in Moodle and drops it into a per-course folder on your computer. No accounts. No cloud API. Nothing leaves your browser.

Everything a download button should be.

Quiet when you don’t need it, obvious when you do.

One click

A quiet icon sits at the right edge of every file. Hover a row and it becomes a Save button.

Save the whole section

A Save all button on each section header, with a counter, a progress bar, and a retry for anything that failed.

Organized by course

Files land in a folder per course. Pick an existing folder or create one the first time — or let Moodrop name it after the course.

Any folder, even cloud ones

Choose a folder synced by Google Drive, OneDrive, Box, or iCloud and it just works. No API keys, no sign-in.

Knows what you have

Saved files get a green check. Delete a file and the check goes away. Name clashes? Keep both or replace.

Private by design

Files go from Moodle straight to your folder. No server, no account, no analytics.

Nothing leaves your browser.

Moodrop has no server of its own. It downloads a file from your Moodle using your signed-in session — exactly what clicking the link does — and writes it to the folder you chose. It only runs on the Moodle sites you add, and asks for the least permission it can.

Questions

Is Moodrop official?

No. It’s an unofficial tool and isn’t affiliated with Moodle Pty Ltd. “Moodle” is their trademark.

Which browsers work?

Chrome 111 or later. Other Chromium-based browsers that support the File System Access API (Edge, Brave…) should work too, but they haven’t been tested.

Will it work with my school’s Moodle?

It isn’t tied to any one school — you add the Moodle you use. Themes and versions vary, so a few layouts may need tweaks. If something doesn’t show up, please open an issue.

Why does Chrome ask for folder access again after a restart?

That’s Chrome’s rule for folders a website or extension can write to. Moodrop shows a short prompt for it. Choose “Allow on every visit” in Chrome’s dialog and it stops asking.

Can I save straight to Google Drive or OneDrive?

Yes — choose the folder their desktop app syncs. Moodrop only writes to a folder on your computer, so there are no API keys or sign-ins.
