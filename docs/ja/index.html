資料の保存を、いちばん軽く。

普段は静かに、押したいときにはそこに。

ワンクリック

資料の右端に、控えめなアイコン。ポインタを乗せると「保存」ボタンになり、押すだけで終わります。

セクションをまとめて

見出しの「すべて保存」で、その週の資料をまとめて。件数と進捗が見えて、失敗したものだけやり直せます。

科目ごとに整理

資料は科目ごとのフォルダへ。初めての科目では、既存のフォルダか新規作成かを選べます。科目名での自動作成にも対応しています。

同期フォルダも使える

Google ドライブ、OneDrive、Box、iCloud の同期フォルダを選べば、そのまま使えます。APIキーも、ログインも不要です。

保存済みが一目で分かる

保存した資料には緑のチェック。ファイルを消せば、チェックも消えます。同じ名前があれば「別名で保存」か「上書き」を選べます。

外には送らない

資料はMoodleから、あなたのフォルダへ直接。サーバーも、アカウントも、アクセス解析もありません。

科目ページを開いて「保存」を押すだけ。初めての科目では、保存先を選びます。

資料は、外に出ません。

Moodropにはサーバーがありません。あなたのログイン状態でMoodleから資料を取得し（リンクをクリックしたときと同じです）、選んだフォルダに書き込むだけです。動くのは登録したMoodleサイトだけで、求める権限も最小限です。

よくある質問

Moodropは公式のツールですか？

いいえ、非公式です。Moodle Pty Ltd とは関係ありません。「Moodle」は同社の商標です。

どのブラウザで使えますか？

Chrome 111以降です。EdgeやBraveなど、File System Access API に対応したChromium系のブラウザでも動くはずですが、確認はしていません。

自分の学校のMoodleでも使えますか？

特定の学校には固定していません。使うMoodleを、自分で登録します。テーマやバージョンで画面の作りが違うため、うまく表示されないレイアウトもあるかもしれません。その場合は、Issueで教えてください。

ブラウザを再起動すると、フォルダへのアクセスをまた聞かれるのはなぜ？

Chromeが、ウェブサイトや拡張機能に書き込みを許すフォルダに設けているルールです。Moodropが短い案内を出します。Chromeのダイアログで「サイトを開くたびに許可」を選ぶと、次回から聞かれません。

Google ドライブやOneDriveに直接保存できますか？

はい。各アプリが同期しているフォルダを選んでください。Moodropが書き込むのはパソコン上のフォルダだけなので、APIキーもログインも要りません。
