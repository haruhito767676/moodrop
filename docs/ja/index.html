Moodrop 特長使い方プライバシーGitHub English

Moodleの資料を、
ワンクリックで好きなフォルダへ。

Moodrop は、Moodleの資料の横に保存ボタンを置いて、パソコンの科目ごとのフォルダに保存します。アカウントもクラウドAPIも要らず、すべてブラウザの中で完結します。

入手する使い方を見る

Chromeウェブストアにはまだありません。GitHubから、1分で導入できます。

moodle.example.ac.jp
情報工学I
第1回
講義資料 第1回.pdf
演習問題 第1回.pdf
参考スライド.pptx

触ってみてください。実際の動きの再現です。資料にポインタを乗せて、保存を押します。

ダウンロードボタンは、こうあるべき。

必要ないときは静かに、必要なときははっきりと。

ワンクリック

資料の右端に、控えめなアイコン。行にポインタを乗せると、保存ボタンになります。

セクションをまとめて

見出しの「すべて保存」。件数と進捗バーが出て、失敗したものだけ再試行できます。

科目ごとに整理

資料は科目ごとのフォルダへ。初めての科目では既存のフォルダか新規作成かを選べます。科目名での自動作成も。

クラウドの同期フォルダでも

Google ドライブ、OneDrive、Box、iCloud の同期フォルダも選べます。APIキーもログインも要りません。

保存済みが分かる

保存した資料には緑のチェック。ファイルを消すとチェックも消えます。同名なら「別名で保存」か「上書き」。

プライバシーを最優先

資料はMoodleから、あなたのフォルダへ直接。サーバーも、アカウントも、アクセス解析もありません。

1分で準備完了。

3つの手順。案内のページがそのまま導いてくれます。

フォルダを選ぶ

資料を入れるフォルダを選びます。中に、科目ごとのフォルダが作られます。

Moodleを追加

あなたのMoodleのURLを入力します。Chromeが許可を求めるのは、そのサイトだけです。

保存する

科目ページを開いて、保存を押します。初めての科目では、保存先を選びます。

外には、何も送りません。

Moodrop には専用のサーバーがありません。あなたのログイン状態でMoodleから資料を取得し（リンクをクリックしたときと同じです）、選んだフォルダに書き込むだけ。動くのは、あなたが追加したMoodleサイトだけで、権限も最小限です。

プライバシーポリシーを読む →

storage設定と、保存した資料の記録を覚えます。
scripting有効にしたサイトに、保存ボタンを表示します。
activeTabポップアップで、このタブがMoodleかを調べます。
追加したサイト1サイトずつ確認します。いつでも解除できます。

よくある質問

Moodropは公式のツールですか？

いいえ。非公式のツールで、Moodle Pty Ltd とは関係ありません。「Moodle」は同社の商標です。

どのブラウザで使えますか？

Chrome 111 以降です。File System Access API に対応した他のChromium系ブラウザ（Edge、Braveなど）でも動くはずですが、確認はしていません。

自分の学校のMoodleでも動きますか？

特定の学校には固定されず、使うMoodleを自分で追加します。テーマやバージョンによって画面の作りが違うため、表示されないレイアウトがあるかもしれません。その場合は、Issueでお知らせください。

ブラウザを再起動すると、フォルダへのアクセスをまた聞かれるのはなぜですか？

Chromeが、ウェブサイトや拡張機能が書き込めるフォルダに設けているルールです。Moodropが短い案内を出します。Chromeのダイアログで「サイトを開くたびに許可」を選ぶと、聞かれなくなります。

Google ドライブや OneDrive に直接保存できますか？

はい。それぞれのデスクトップアプリが同期しているフォルダを選んでください。Moodropが書き込むのはパソコン上のフォルダだけなので、APIキーもログインも要りません。
