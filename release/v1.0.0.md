# Moodrop 1.0.0

**Save Moodle course files to any folder with one click.**

The first release of Moodrop: a small Chrome extension that puts a save button next to the files in Moodle and drops them into per-course folders on your computer. No accounts, no cloud API setup, and nothing leaves your browser.

## Highlights

- **One-click save.** A quiet icon at the right edge of every file turns into a Save button when you hover it.
- **Save a whole section.** A Save all button on each section header, with a counter and a progress bar, and a retry for anything that failed.
- **Organized by course.** Pick a folder once per course (Moodrop suggests existing folders with a similar name), or let it create folders from course names automatically.
- **Any folder, including cloud folders.** Choose a folder synced by Google Drive, OneDrive, Box, or iCloud. No API keys and no sign-in.
- **Knows what you already have.** Saved files get a green check, and it goes away if you delete the file. Name clashes: keep both or replace.
- **Works with your Moodle.** Not tied to one school: you enable the Moodle sites you use.
- **Private by design.** Files go from Moodle straight to your folder. No server, no account, no analytics.
- **English and Japanese**, following your browser language.

## Install

1. Download **moodrop-1.0.0.zip** below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder (the one containing `manifest.json`).
4. A welcome page opens. Choose a save folder, add your Moodle's URL, and you're ready.

Requires Chrome 111 or later. Other Chromium-based browsers should work but have not been tested.

## Good to know

- Moodrop is built and tested mainly against one university's Moodle. Themes and versions differ, so a few layouts may not show the buttons. If that happens, please [open an issue](https://github.com/haruhito767676/moodrop/issues) (the page address and what you see help a lot).
- After you restart your browser, Chrome asks you to allow access to the save folder again. Choosing "Allow on every visit" in Chrome's dialog stops it from asking.
- Chrome refuses a few folders, such as your home folder or the Downloads folder itself. Choose or create a subfolder inside it.
- Streaming video is not downloaded; Moodrop saves files that Moodle serves as files.
- Moodrop is an unofficial tool and is not affiliated with Moodle Pty Ltd.

# Moodrop 1.0.0（日本語）

**Moodleの資料を、ワンクリックで好きなフォルダへ。**

Moodropの最初のリリースです。Moodleの資料の横に保存ボタンを置いて、パソコンの科目ごとのフォルダに保存する、小さなChrome拡張機能です。アカウントも、クラウドAPIの設定も要りません。取得も保存も、すべてブラウザの中で完結します。

## 特長

- **ワンクリックで保存。** 資料の右端の控えめなアイコンが、ポインタを乗せると「保存」ボタンになります。
- **セクションをまとめて保存。** セクション見出しの「すべて保存」。件数と進捗バーが出て、失敗したものだけ再試行できます。
- **科目ごとに整理。** 科目ごとに保存先を1回選ぶだけ（名前が近い既存フォルダを提案します）。科目名で自動的にフォルダを作る設定もあります。
- **どのフォルダでも、クラウドの同期フォルダでも。** Google ドライブ、OneDrive、Box、iCloud の同期フォルダを選べます。APIキーもログインも要りません。
- **保存済みが分かる。** 保存した資料には緑のチェック。ファイルを消すと、チェックも消えます。同名のファイルは「別名で保存」か「上書き」を選べます。
- **あなたのMoodleで使える。** 特定の学校に固定されず、使うMoodleサイトを自分で有効にします。
- **プライバシー重視の設計。** 資料はMoodleから、あなたのフォルダへ直接。サーバーも、アカウントも、アクセス解析もありません。
- **日本語と英語**に対応（ブラウザの言語に合わせて切り替わります）。

## 導入

1. 下の **moodrop-1.0.0.zip** をダウンロードして、解凍します。
2. `chrome://extensions` を開いて、**デベロッパー モード**をオンにします。
3. **パッケージ化されていない拡張機能を読み込む**を押して、解凍したフォルダ（`manifest.json` があるフォルダ）を選びます。
4. 案内のページが開きます。保存先のフォルダを選び、使うMoodleのURLを入れれば、準備完了です。

Chrome 111 以降が必要です。他のChromium系ブラウザでも動くはずですが、確認はしていません。

## 知っておいてほしいこと

- Moodropは、主に特定の大学のMoodleで作り、確認しています。テーマやバージョンによって画面の作りが違うため、ボタンが表示されないレイアウトがあるかもしれません。その場合は[Issue](https://github.com/haruhito767676/moodrop/issues)でお知らせください（ページのアドレスと、見えている画面があると助かります）。
- ブラウザを再起動すると、Chromeが保存先フォルダへのアクセスをもう一度確認します。Chromeのダイアログで「サイトを開くたびに許可」を選ぶと、確認されなくなります。
- Chromeは、ホームフォルダやダウンロードフォルダそのものなど、いくつかのフォルダを選ばせてくれません。その場合は、その中のサブフォルダを選ぶか、作ってください。
- ストリーミング動画は保存できません。Moodleがファイルとして配信している資料が対象です。
- Moodropは非公式のツールで、Moodle Pty Ltd とは関係ありません。
