# Moodrop 1.0.1

**Fixes the text on every screen.** In 1.0.0, labels and messages showed internal names (such as `navGeneral`) instead of readable text. Please use 1.0.1 instead of 1.0.0.

## What changed

- **Screens show real text again** (English and Japanese). The translation files were written in a form Chrome could not read, so Chrome skipped them. A test now checks for this kind of mistake.
- **The extension ID is now fixed.** Your settings, save folder, and registered sites are kept even if you move the extension's folder and load it again from the new place.
- **README:** a note about keeping the extension's folder in place, and how to update.

## Update

1. Download **moodrop-1.0.1.zip** below and unzip it.
2. Replace the files in the folder you loaded before (or load the new folder), then press the reload (↻) button on the extension's card at `chrome://extensions`.

> If you installed 1.0.0, the extension ID changes once with this version, so you will see the welcome page again and need to choose your save folder and add your Moodle site one more time. This will not happen again.

New to Moodrop? See the [1.0.0 notes](v1.0.0.md) for what it does and how to install it (use the 1.0.1 ZIP).

# Moodrop 1.0.1（日本語）

**すべての画面の文言を直しました。** 1.0.0 では、ラベルやメッセージが、読める文章ではなく、内部の名前（`navGeneral` など）のまま表示されていました。1.0.0 ではなく、1.0.1 をお使いください。

## 変更点

- **画面の文言が、正しく表示されるようになりました**（英語と日本語）。翻訳ファイルの書き方が、Chromeが読める形になっておらず、Chromeに読み飛ばされていました。この種の間違いを検出するテストも追加しました。
- **拡張機能のIDを固定しました。** 拡張機能のフォルダを動かして、新しい場所から読み込み直しても、設定・保存先・登録したサイトが残ります。
- **README:** 拡張機能のフォルダを動かさないことと、更新の方法を追記しました。

## 更新の方法

1. 下の **moodrop-1.0.1.zip** をダウンロードして、解凍します。
2. 以前に読み込んだフォルダの中身を置き換えて（または、新しいフォルダを読み込んで）、`chrome://extensions` の拡張機能のカードにある再読み込み（↻）ボタンを押します。

> 1.0.0 を入れていた場合、このバージョンで拡張機能のIDが1度だけ変わります。そのため、案内の画面がもう一度開き、保存先のフォルダとMoodleサイトを、あらためて設定する必要があります。今後は起きません。

はじめての方は、機能と導入方法を[1.0.0のノート](v1.0.0.md)でご覧ください（ZIPは1.0.1のものをお使いください）。
